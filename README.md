# Velvet Avenue Marketplace v2

Prototype multi-vendor marketplace untuk presentasi.

## Konsep
Velvet Avenue adalah platform yang mempertemukan buyer dan seller. Platform bukan toko
yang menjual barang sendiri. AI Shopping Agent membantu buyer memahami kebutuhan,
mencari produk dari berbagai seller, memberi match score, dan menjelaskan rekomendasi.

## Sudah tersedia
- Buyer / Seller / Admin account
- Login dan register
- Seller store
- Seller Center
- Product management
- Kategori, brand, size, color, SKU, stock, weight, discount
- AI natural-language search + local fallback
- Product matching dan ranking lintas seller
- Cart
- Address
- Checkout dan order
- Seller order view
- Review schema
- Admin overview / analytics dasar
- Report schema
- Warna dan visual marketplace modern

## Sengaja belum dibuat
- Payment gateway nyata
- Mobile app
- Public URL / deployment
